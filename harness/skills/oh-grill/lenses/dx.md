# DX Lens

Developer experience perspective: is this pleasant to integrate, use, and maintain?

## Questions

1. **First use** — What's the sequence from "never seen this" to "it works"? How many commands? What assumptions?
2. **Error messages** — When something fails, does the output tell you what went wrong AND how to fix it?
3. **API coherence** — Are function/endpoint names predictable? Do similar things look similar?
4. **Onboarding friction** — What would surprise a new user? What would make them give up?
5. **Documentation quality** — Is there a getting-started path? What's missing?
6. **Migration path** — If this replaces something, how do existing users transition?

## Output

- DX friction points (critical / notable / minor)
- Onboarding assessment
- Score 0-10 with justification
- Recommended API amendments
