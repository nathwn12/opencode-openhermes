# Design Lens

User experience perspective: does this plan create a good product experience?

## Questions

1. **User journey** — Walk through the primary flow. How many steps? Where might users get confused?
2. **Consistency** — Does this match existing design patterns in the product?
3. **Accessibility** — Keyboard navigation, screen readers, color contrast, focus states.
4. **Responsive behavior** — How does it work on different screen sizes?
5. **Error states** — What happens when something goes wrong? Is the error message helpful?
6. **AI slop detection** — Generic UX patterns, unnecessary complexity, placeholder interactions.

## Output

- UX concerns (critical / notable / minor)
- Consistency assessment
- Score 0-10 with justification
